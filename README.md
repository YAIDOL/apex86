# APEX / 86

Браузерна мінігра зі спорткарами та інтерактивним гаражем.

**Грати:** https://yaidol.github.io/apex86/

## Керування

- `←` / `→` або `A` / `D` — плавна зміна однієї з двох смуг.
- `Space`, `↓` або `S` — сильне гальмування до повної зупинки. Після відпускання авто автоматично розганяється.
- `Escape` або `P` — пауза.
- На телефоні — екранні кнопки.

## Гараж

Власноруч розроблені параметричні ігрові моделі за Toyota GT86, Toyota Supra A80 та Nissan GT-R R35. Код геометрії — `cars.js`; сторонні автомобільні моделі не використані. Це авторські інтерпретації реальних автомобілів, не точні CAD-копії чи офіційні активи виробників.

Є окремі кузовні панелі, відкриті колісні арки, диски, вентильовані гальма й супорти, оптика, вихлоп, спойлери, двері, сидіння, кермо, панель приладів та педалі. Доступні обертання мишкою, наближення, салон від першої особи, відкривання дверей, зняття даху, ракурси деталей, фарбування й завантаження моделі в GLB. Портативний GLB містить геометрію та однотонні матеріали; текстові декалі й вебанімація залишаються у грі.

Вибір авто, фарба та рекорд зберігаються у браузері. Гра автоматично стає на паузу при втраті фокуса. Звук вимкнений за замовчуванням.

## Запуск і перевірка

Без встановлення залежностей чи збірки:

```sh
node server.mjs
node --test game.test.js cars.test.js
```

Сайт відкриється на http://127.0.0.1:5174. GitHub Pages публікує корінь гілки `main`; `.nojekyll` вимикає Jekyll.

Three.js 0.181.2 та його допоміжні модулі розміщено в `vendor/`, ліцензія — `vendor/LICENSE`. Шрифти Manrope і Barlow Condensed завантажуються через Google Fonts, із системним запасним шрифтом.
